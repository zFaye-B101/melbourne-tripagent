# 复用 BFF 的安全边界（本地阶段）

`llm-gateway-kit/http` 是一个可用模拟请求测试的服务端处理器，不是可直接公开的代理服务，也没有托管或用户体系。包内已有保守预算账本及 Cloudflare SQLite Durable Object 适配器，但它们尚未接入线上 HTTP 服务，也没有经过真实跨实例并发验证。静态 WorkBuddy 页面只能访问另行部署的 BFF；API Key、模型、任务提示词和输出 Schema 必须由服务端固定，不能写入前端或由浏览器请求指定。

## 开启前必须由部署方实现

1. `verifyCaller` 在服务端执行调用者策略，并给出无法由浏览器自报的 `subjectKey`。正式对外服务宜验证身份或抗滥用挑战；有严格全局费用硬停的小范围匿名演示可以使用服务端固定的共享主体，但这**不验证用户**，第三方可能耗尽额度。`Origin` 和请求中的 `consent:true` 都不是身份凭据；后者也不能证明用户确实点击了页面上的同意按钮。
2. `consumeRateLimit` 使用面向该主体的限流设施。限流用于缓解滥用，不能充当费用账本或全局硬配额。
3. `reserveBudget` 在所有实例之间原子地预留一次调用的最坏费用，并同时执行用户配额与账户预算硬停。`maxCostUnits` 是服务端配置的正整数上界，单位由部署方固定为一种最小计费单位（例如微分），不得混用币种或使用浮点金额；只有模型、输入和输出都存在可证明的费用上界时，这个数值才有意义。没有证明时必须保持关闭。
4. `settleBudget` 记录调用结果；超时、模型异常或结算失败不能推断为“未计费”，不得自动退还预留。当前处理器的本地锁定状态不是分布式锁，也不能代替持久化的预算状态。

处理器默认关闭；即使显式开启，缺少任一上述钩子、有效 Origin 或费用上界配置时也不得调用模型。前端请求只允许文本和本次同意标记。项目自己的任务 `validateOutput`、业务事实核验及失败回退仍由项目负责。

## 仍未满足的公开发布条件

- 实现并验证服务端决定的配额主体、跨实例限流及原子费用硬停；较大范围公开服务还需身份或挑战。小范围匿名演示须明确接受共享额度被耗尽的风险；模拟回调通过不等于这些设施已存在。
- 限定并验证供应商调用的最大成本，确认账户层面的实际扣费和停用行为。百炼适配器支持 `max_completion_tokens`，TripAgent 已为指定模型设置它；但仍须核对输入上界、供应商实际计费和账号价格。OpenAI 适配器也没有统一响应体上限。当前代码不能仅凭 `maxCostUnits` 证明人民币费用硬上限。
- 在真实 SQLite-backed Durable Object 上验证单一预算实例的持久性、并发串行及失败语义，把账本接入 HTTP 钩子；本地模拟存储测试不是云端验证。
- 核对供应商的数据保留、训练用途、地域与计费条款，并让用户在页面上明确同意发送本次文本。
- 在真实 HTTPS BFF 与目标地区普通网络上测试拒绝、并发、超时、回退和密钥不泄漏，再决定是否公开启用。

Cloudflare 官方说明其 [Workers 限流](https://developers.cloudflare.com/workers/runtime-apis/bindings/rate-limit/)按位置计数、最终一致；[AI Gateway 支出限制](https://developers.cloudflare.com/ai-gateway/features/spend-limits/)在并发突发时也可能短暂超额。因此两者都不能单独作为本项目要求的全局费用硬停。

本地测试只用模拟模型与模拟策略，未读取真实密钥、未调用真实 API、未部署。

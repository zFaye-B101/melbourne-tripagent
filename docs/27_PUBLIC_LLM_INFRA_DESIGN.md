# 真实 LLM 基础设施设计（本地草案，2026-09-16）

## 本阶段结论

公开 WorkBuddy 网址仍只使用规则生成。没有发布服务端、调用真实 API、读取密钥，也没有把 `LLM_ENABLED` 打开。以下是未来公开试用所需的边界和本地已完成的构件，不是上线验收记录。`llm-gateway-kit` 是开发者自己复用的内部组件；向长辈展示的只有墨尔本旅行网页，不展示 API 配置、组件接口或“可迁移”能力。

本次是小范围演示：网页不要求登录、邀请码或默认的人机验证。省去访问门槛不等于放弃后台费用保护；若有人转发链接或直接请求接口，仍可能消耗演示额度。

## 建议的请求路径

1. 浏览器展示数据接收方与单次发送说明；用户主动同意后，仅向独立 HTTPS BFF 发送本次旅行文本和同意标记。原有静态页面不存密钥，也不展示 API 配置。
2. BFF 校验允许的 Origin 与请求形状，使用服务端固定的演示配额主体；这只是共享预算标识，**不是用户身份验证**。Origin 也不是身份凭据。接口不要求访问者输入邀请码。
3. BFF 执行保守的总体限流；对同一预算期，通过同一个 SQLite-backed Durable Object 原子预留一次模型调用的最坏费用。预留失败直接回退规则，不尝试供应商 API。匿名演示无法阻止他人耗尽共享额度，只能保证费用及调用量有界。
4. 只对已放行请求调用服务端固定的百炼模型与任务。供应商结果还需经结构化输出校验及 TripAgent 的事实/路线规则核验；失败保持原始输入并给出明确的规则回退说明。
5. 成功或结果不明均记录最终状态，预算不自动返还。服务端日志不记录 API Key、旅行原文或供应商完整响应。

## 已有、缺失与顺序

| 边界 | 本地状态 | 上线前仍需完成 |
| --- | --- | --- |
| 服务端任务与百炼适配 | `llm-gateway-kit` 可通过模拟请求测试；TripAgent 对百炼请求固定 `max_completion_tokens=4096` 且关闭思考 | 真实 HTTPS 托管与实际供应商响应验收 |
| HTTP 边界 | 本机可选接入共享预算；公网模型仍硬拒绝 | 确定 HTTPS 托管、跨域域名、同意文案与拒绝/回退 E2E |
| 预算账本 | 整数单位保守预留、重复请求拒绝、费用不明不退款；SQLite Durable Object 已在隔离本机运行器做预留和重启检查 | 创建真实云端对象，确认所有请求指向同一预算实例，并实测云端并发、持久与故障 |
| 费用上界 | 已按官方规格和原价推算指定条件下 0.81 元/次的上取整值，尚未当成账号实际费用承诺 | 核对账号地域/产品/实际价格、用完即停与真实账单；再确定服务端预留单位和总额度 |
| 访问与滥用 | 已决定演示版不做登录、邀请码或默认验证码 | 仍需总体限流、共享调用/费用硬停，并接受匿名访问可能耗尽额度的可用性风险；若测试发现滥用，再讨论额外验证 |
| 地区可达性 | 未实测 | 从中国普通网络访问现有静态页、BFF 及完整交互 |

Cloudflare [SQLite-backed Durable Object](https://developers.cloudflare.com/durable-objects/api/sqlite-storage-api/) 提供可在单个对象内执行的同步事务，适合演示版的单预算期原子账本；它不等于供应商账单硬停。Cloudflare [Workers 限流](https://developers.cloudflare.com/workers/runtime-apis/bindings/rate-limit/)是按边缘位置计数且最终一致，只能减缓请求，不能代替原子预算。若使用百炼免费额度，还需在该账号、该模型的控制台核实[免费额度用完即停](https://help.aliyun.com/zh/model-studio/new-free-quota)已开启且生效；不能凭注册或本地配置推断。上述基础设施仍需账号、资源绑定和实测，不能由本地单元测试代替。

## 发布门槛

保持现有 BFF 的非回环地址默认拒绝。演示版虽不要求访问者身份，仍必须先完成真实预算存储接线与并发验证、总体限流、费用上界与账户停用确认、隐私说明与用户同意、目标地区端到端测试，才重新审查这道拒绝门槛。不得仅更改环境变量就开放模型。详细检查见 [线上发布门槛](25_ONLINE_LLM_RELEASE_GATE.md)。

本机接线观察与证据边界见 [共享预算本机验收](28_LOCAL_SHARED_BUDGET_SMOKE.md)。
指定模型的资料推算和账号待核实项见 [百炼费用上界研究](29_DASHSCOPE_COST_BOUND_RESEARCH.md)。

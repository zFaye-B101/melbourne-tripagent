# 同行人数与票型：设计与实现记录

日期：2026-09-17。范围：Melbourne 1–3 天 Demo 的自然语言理解、精细调整和预算展示。人数修复已在本地实现，发布仍以实际部署记录为准。

实施说明：保留严格的 Draft v2 Schema，不向其偷偷追加字段；同行总人数由本地规则从原文提取，并在规范化请求中与 v2 草稿的票型字段合并。提示词已明确禁止把泛称「两个人」填成成人票；票型状态由程序计算。此为设计中允许的兼容迁移层，避免同时升级所有模型提供商的输出契约。

## 决策

把「同行总人数」与「能用于票价计算的人数」分开。`两个人`能证明总人数为 2，**不能**证明两张成人全票。不能通过把成人证据校验里的 `/成人/` 改成 `/人/` 来消除回退：那会把儿童、优惠票旅客也算成成人全票。

行程安排可以继续；票型未明确时不得显示看似覆盖全团的门票、交通合计，也不得把默认的「1 位成人」表述为用户给出的事实。页面只补问一个最有价值的问题，用户可通过精细调整回答。

## 数据契约

下一版抽取契约增加 `party.totalTravelers: number | null`，上限沿用当前人数上限 20；原有 `adultFullFareCount`、`concessionEligibleCount`、`childAges` 保持不同含义。由于当前 Draft v2 使用严格 Schema 且禁止额外字段，应创建版本化的新 Draft 契约（或明确的兼容迁移层），不能悄悄给 v2 追加字段并继续宣称其 Schema 未变。

- `totalTravelers=2` 的证据可为「两个人」「2 人」「两位同行」等原文连续片段。
- `adultFullFareCount` 只从明确的「成人」「大人」「成年人」「adult」及数字抽取；校验器可加入这些同义词，但不能加入泛称「人」。按全票只是费用估算假设，界面须明示优惠资格未核实。
- 儿童年龄只从明确年龄抽取；「一大一小」能证明总人数 2、成人 1，但不能猜孩子年龄或儿童票价。
- 「学生」「老人」本身不能证明澳洲优惠票资格；只有明确的优惠票选择才进入 `concessionEligibleCount`，仍提示购票前核实资格。
- 每个非空字段保留独立、逐字的 evidence；输入中的总人数与已知票型人数相加冲突时，报告冲突，不静默选择一方。

在规范化请求中保存 `totalTravelers` 的值、来源和证据，并由程序推导 `ticketBreakdownStatus = complete | partial | unknown | conflict`。它不是模型可自行填写的字段。已知票型人数不能超过总人数；未分类人数 = 总人数 - 已知票型人数。没有写总人数、但明确列出完整票型组合时，可由组合求和；否则保持总人数未知。默认「1 位成人试算」只能用于完全没有人数线索的旧路径，必须标为默认而非事实。

## 行为与文案

1. 输入「两个人」：理解结果为「2 人同行 · 票型待确认」，LLM 草稿可合法通过，不应因误填成人票而回退。先生成不依赖票型的路线；预算区域写「还不知道两位分别适用哪种票，暂不能估算整团门票与交通费用」，不显示整团合计或「按 1 位成人估算」。
2. 如果用户明确「两位成人」：使用 2 位成人进行全票参考估算，并保留「优惠资格与实际票价以购票时为准」；「两位大人」应有相同的抽取与证据校验结果。
3. 如果只有部分票型，例如「一大一小」：保留已知的 1 位成人和总人数 2；儿童年龄与相应费用仍为未知。不得把未知部分按成人票补齐。
4. 提问一次只问一个问题。只有总人数时问：「这 2 位分别是成人，还是有儿童或优惠票旅客？」；已知有儿童但无年龄时优先问：「孩子几岁？这会影响票价估算。」可以跳转到「同行人和预算」精细调整；不用要求用户改写原句。
5. 精细调整若与原文总人数冲突（如输入 2 人，选择 3 位成人），明确展示「你写了 2 人，但精细调整是 3 人」，提供跳转到对应设置；不要悄悄覆盖。用户确认修改后的选择才可作为新计算依据。
6. `ticketBreakdownStatus != complete` 时，预算对整团门票、公共交通和总预算比较均为「待确认」；可以保留已核验的单人票价或已知部分，但标清覆盖范围，不能当作全团最低费用。

## 实施顺序与验收

先更新 Draft/schema/提示词/证据校验，再更新规范化请求和规则解析，最后更新精细调整、冲突跳转与预算显示。保留旧草稿兼容路径，未通过新契约时仍可回退规则，但规则路径也必须承认「总人数已知、票型未知」。已有成功行程不得因补问或失败而消失。此设计暂不与 WorkBuddy 正在处理的防滥用代码合并发布。

回归文本限定为以下 8 条，不为单一句子做特判：

| 输入片段 | 预期 |
|---|---|
| 两个人 | 总数 2；票型未知；无整团预算 |
| 2 人同行 | 总数 2；票型未知；与「两个人」一致 |
| 两位成人 | 成人 2；可按全票参考估算 |
| 两位大人 | 成人 2；与「两位成人」一致 |
| 两个大人带一个 8 岁孩子 | 总数 3、成人 2、儿童 8 岁 |
| 一大一小 | 总数 2、成人 1；儿童年龄未知，不补成人票 |
| 两个人，其中一个是 8 岁孩子 | 总数 2、儿童 8 岁；另一人的票型不推断 |
| 两个人 + 精细调整为 3 位成人 | 展示冲突并能跳转；未确认前不生成错误预算 |

通过标准：8 条的本地规则与 LLM 路径在人数语义上保持一致；所有抽取值有原文证据；未分类旅客不被算作成人全票；完整票型可估算、部分/未知票型不会显示误导性的整团费用；冲突跳转与回退在浏览器实测。完成本地验收后再单独决定是否覆盖原线上链接。

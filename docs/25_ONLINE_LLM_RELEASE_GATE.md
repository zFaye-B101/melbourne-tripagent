# 真实 LLM 线上发布门槛（2026-09-16）

## 当前状态

- 既有公开应用是 `Melbourne TripAgent`，appId 为 `wbapp_cFS2bnfmLJu6A0MoVMgysh`，网址是 <https://melbourne-tripagent.app.workbuddy.host/>。它是静态站；正常线上生成仍使用本地规则，**不是线上 LLM**。
- 本机 BFF 已使用固定 8 类输入做真实模型验收。不同批次分别为 7/8 和 5/8 采用 LLM；其余输入均因证据不足安全回退。模型采纳有波动，这不是稳定性通过，也不能代替线上浏览器与服务端验收。详情见 [八类输入验收](24_LOCAL_NLU_EIGHT_CASE_ACCEPTANCE.md)。
- 上述较好的本机批次使用了仅限回环地址的可选推断清理开关；生产请求无法启用该开关。不能把本机采纳数字直接当作生产预期。
- 发布目录 `site/dist/client/` 与既有网址的当前首页内容不同。不能据此推断线上已包含本地最新修改。
- 当前机器的 Wrangler 未登录部署账户；个人版 WorkBuddy 是否能为这个既有静态应用托管带密钥的服务端，尚未得到确认。
- 2026-09-16 本地已修复一个发布阻断点：浏览器收到 BFF 的 `scope_error` 后不再用本地规则重新解析为可生成行程；即使本地规则会判为 `ready`，也保持范围阻断。全量 309 个 Vitest、5 个 Node 测试、类型检查、lint 和静态发布包校验通过；本次没有部署。
- 现有 Cloudflare Worker 只是 BFF 候选，尚未选定托管账户、正式 HTTPS 域名或中国普通网络可达性。`wrangler whoami` 显示当前机器未登录；不能把本地构建通过视为线上服务就绪。
- 2026-09-16 本地第二阶段已将百炼传输逻辑抽入独立组件，TripAgent 保留原有本机限制、免费额度策略、熔断及规则回退；此重构没有打开线上 LLM，也没有消除以下发布门槛。
- 随后的本地加固在 TripAgent BFF 加入明确的非本机拒绝门槛：即使误把 `LLM_ENABLED` 打开，并配置供应商密钥和普通限流，公开地址也不会调用模型，只回退规则。四类供应商均有模拟请求回归测试。未来接入经验证的共享演示配额、原子预算及其他费用保护后，必须重新审查并显式修改这一门槛；不能只改环境变量就上线。
- 后续本地工作已在独立 `llm-gateway-kit` 加入保守预算账本与 Cloudflare SQLite Durable Object 适配器，百炼请求也设置了输出 token 上限；这些只是构件与模拟测试，尚未创建云端资源、接通共享配额/预算钩子或证明单次人民币费用上界。架构和待办见 [基础设施设计](27_PUBLIC_LLM_INFRA_DESIGN.md)。
- 共享预算现已接入 BFF 的可选本机通路，并在无密钥的隔离 Wrangler 运行器验证了超额拒绝、预留后不返还和重启后继续拒绝；公网门槛仍不变。详见 [本机验收](28_LOCAL_SHARED_BUDGET_SMOKE.md)。上述“未接通预算钩子”特指**公网生产通路**。

## 放行真实模型的顺序

1. 本地完成通用证据规则修正，继续使用不超过 10 条不同文本的固定验收集；重复运行需记录通过、回退、耗时和失败类别，不能只报 HTTP 200。
2. 前端只在配置了受信任的 HTTPS BFF 后显示单次自愿试用入口；未点击前不发送旅行原文。失败时保留原输入与已有行程，并明确告知规则回退，不把规则结果标成 AI 结果。
3. 确定 BFF 托管账户和正式域名。BFF 保存 API Key；静态文件和浏览器请求中都不得包含 Key。服务端只允许既有 WorkBuddy 域名跨域调用，但不能把 CORS 当身份验证。
4. 本次小范围演示不设置登录、邀请码或默认验证码；改用服务端固定的共享演示配额、总体限流、经验证的原子费用硬停，并在百炼控制台核实该模型免费额度用完即停（若使用免费额度）。共享标识不是用户身份；匿名访问可能耗尽额度，必须接受这一可用性限制。费用上界、停用或限流缺失时保持模型调用关闭。
5. 核对模型供应商的原文数据保留、训练用途及地域条款，并在界面说明会把本次输入发送给哪家供应商；用户需明确选择后才发送。
6. 在生产 HTTPS BFF 上实测超时、拒绝、限流、版本不匹配和规则回退；再从既有 WorkBuddy 页面完成端到端测试，包括普通中国网络可达性。当前本地 60 秒模型测试不能代替生产 4 秒超时的验证。
7. 所有门槛通过并得到本次生产配置的明确确认后，才打开线上模型调用。更新页面时必须按注册标记覆盖同一 appId，不能新建应用或改变网址；发布后独立核对资源与真实请求。

## 已核实的百炼条款边界

阿里云官方[隐私说明](https://help.aliyun.com/zh/model-studio/privacy-notice)称百炼不会把客户数据用于模型训练，但也会依法存储模型调用数据；[服务协议](https://terms.alicdn.com/legal-agreement/terms/common_platform_service/20230728213935489/20230728213935489.html)第 6.2.5 条称对话数据仅保留服务必需的最短时间，未给出本场景的明确天数。协议第 5.2.2 条对 Token Plan 个人版和 Coding Plan 另有用于服务改进及模型优化的授权，因此上线前必须核实当前 Key 的计费/产品类型；不能把通用 API 的承诺直接套到订阅型 Key。

[免费额度说明](https://help.aliyun.com/zh/model-studio/new-free-quota)指出北京地域的免费额度及“用完即停”取决于具体模型和账号开关；配置文件中的本机确认标记不能证明控制台当下仍有额度或开关仍开启。本轮尝试查看登录后的额度页时浏览器安全检查未放行，未绕过该限制，也未把余额状态当作已核实。

## 未满足时的处理

既有线上规则版保持可用；可以继续本地开发和测试，但不要把它宣传为“LLM 已上线”，也不要将 `.dev.vars`、API Key 或本机回环服务上传到静态站。

Cloudflare 的 [Workers Rate Limiting 绑定](https://developers.cloudflare.com/workers/runtime-apis/bindings/rate-limit/)按边缘位置计数且最终一致，不能单独充当精确的全局配额；[AI Gateway spend limits](https://developers.cloudflare.com/ai-gateway/features/spend-limits/)同样可能因并发突发短暂超出额度。若选用 Cloudflare，仍需另外验证可执行的费用硬停机制，并以此作为打开 `LLM_ENABLED` 的前置条件。
